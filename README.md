# Food Waste Monitoring System

## About the Project
The Food Waste Monitoring System is a Python-based program that analyses the quantity of food prepared, served, and wasted over multiple days. It calculates wastage percentages and identifies days with excessive food waste.

## Objectives
- Record daily meals prepared and served.
- Calculate the quantity of leftover food.
- Calculate daily food wastage percentages.
- Identify days with high food wastage.
- Calculate total food wastage across all days.

## Concepts Used
- Variables and data types
- Lists
- For loops
- Conditional statements
- Arithmetic operators

## How the Program Works
1. The user enters the number of days.
2. The number of meals prepared and served is entered for each day.
3. The program calculates the leftover food quantity.
4. Daily wastage percentages are calculated.
5. Days with more than 20% wastage are identified.
6. Total meals prepared, served, and wasted are calculated.
7. The overall wastage percentage is displayed.

## Conclusion
This project demonstrates how Python lists, loops, and conditional statements can be used to monitor food waste and analyse daily food consumption.
